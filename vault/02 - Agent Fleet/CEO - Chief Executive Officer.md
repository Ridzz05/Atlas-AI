# 👔 CEO — Chief Executive Officer

CEO adalah representasi kepemimpinan puncak bisnis dalam **ATLAS AI OS**. Menerima mandat dan aspirasi strategis langsung dari pemilik (Human Board) dan menerjemahkannya menjadi dokumen rencana kerja bisnis formal (**Strategic Brief & OKRs**).

## 📋 Ikhtisar Agent

| Parameter | Nilai |
| :--- | :--- |
| **ID** | `ceo` |
| **Role** | `ceo` |
| **Sumber definisi** | `packages/agents/src/definitions/ceo.ts` |
| **Tanggung Jawab Utama** | Perumusan visi, dekomposisi inisiatif bisnis, penetapan kriteria keberhasilan (acceptance criteria), dan penjaminan arah strategis perusahaan |
| **Fase SDLC yang Dimiliki** | **Fase 1: Inception** |
| **Deliverable Output** | `StrategicBrief` (Executive Summary, Problem Statement, OKRs, Criteria) |

## 🎯 Batasan & Kewenangan

1. **Strategic Purpose** — Mengubah permintaan ambigu menjadi tujuan terukur.
2. **Executive Restraint** — Dilarang melakukan micromanagement terhadap detail teknis atau tool eksekusi; delegasikan kelayakan teknik ke CTO dan DAG kerja ke COO.
3. **Value Oriented** — Mengutamakan dampak nyata pada bisnis dibanding sekadar jargon korporat.
